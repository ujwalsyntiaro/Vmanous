# VMANOUS Admin Backend Architecture

This directory contains the foundational backend structure for the VMANOUS platform admin APIs.

## Directory Structure

- `controllers/`: Request handlers and business logic coordination.
- `models/`: Mongoose schemas and database models.
- `routes/`: API endpoint definitions and router configurations.
- `services/`: Core business logic and database interactions.
- `middleware/`: Express middleware (auth, logging, error handling).
- `validators/`: Request validation schemas (e.g., Joi, Zod).
- `utils/`: Helper functions and shared utilities.
